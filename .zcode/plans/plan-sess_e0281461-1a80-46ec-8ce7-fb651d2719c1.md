# 安装 agentscope-skill 到 ~/.agents/skills/

把 agentscope-ai/skills 仓库中的 agentscope-skill（AgentScope 2.x 知识技能，与本项目 backend 锁定的 agentscope==2.0.8 匹配）拷贝到跨工具共享的用户级技能目录。

## 步骤

1. **浅克隆仓库到临时目录**
   ```bash
   git clone --depth 1 https://github.com/agentscope-ai/skills.git /tmp/agentscope-skills
   ```

2. **拷贝 skill 目录到 ~/.agents/skills/**
   ```bash
   cp -r /tmp/agentscope-skills/skills/agentscope-skill ~/.agents/skills/agentscope-skill
   ```
   整目录拷贝，保留 SKILL.md、references/、scripts/。

3. **清理临时克隆**：`rm -rf /tmp/agentscope-skills`

4. **验证**：`ls -R` 确认文件齐全、SKILL.md frontmatter 完整；技能在会话启动时发现，装完需新开会话（Settings → Skills 里可确认）。
