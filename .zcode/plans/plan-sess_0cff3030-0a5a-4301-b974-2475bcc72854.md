# agent.py 拆分重构方案（v2：MCP / 技能独立成模块）

## 背景

`backend/app/agent.py`（约 400 行）混着多类相对独立的逻辑，`AgentService.stream()` 约 170 行。按项目既有惯例（扁平 `agent_*` 模块、职责域拆分）拆出五个模块，agent.py 只留编排。

**原则：纯位移，不改行为**——SSE 事件格式、开关降级逻辑、错误路径原样保留，原有中文注释随代码搬走。唯一变化：探测日志的 logger 名随新模块变为 `friday.agent_mcps` / `friday.agent_skills`（`节点[...]` 前缀等日志内容不变，不影响按前缀检索）。

## 新模块（5 个）

### 1. `app/agent_messages.py` — 输入侧消息构造（~60 行）
- `user_message()` ← `_user_message`（多模态附件→base64 DataBlock）
- `replay_msgs()` ← `_replay_msgs`（回放窗口→AgentScope 消息）
- 依赖仅 `files.resolve_stored_image` + agentscope.message，与 AgentService 零耦合

### 2. `app/agent_events.py` — 输出侧事件翻译（~80 行）
- `TOOL_QUERY_KEYS` + `tool_query()` ← `_tool_query`（chip 摘要）
- 新增小类 `ReplyEventTranslator`：持有 `tool_args`/`tool_names`/`announced` 累积状态，`feed(event) -> dict | None` 完成事件→SSE dict 映射（TEXT/THINKING delta、TOOL_CALL 参数累积与 chip 去重），与现逻辑逐行等价

### 3. `app/agent_mcps.py` — MCP 工具挂载（~60 行）
- `mcp_client(enable_tools)` ← `_mcp_client`（含 is_stateful / readOnlyHint / 90s 超时注释）
- `probe_mcp_tools(client)` ← stream() 里的探测段：list_tools 成功记 `节点[MCP工具注册]`、失败仅告警不抛（行为不变：client 仍照常挂载）

### 4. `app/agent_skills.py` — 技能加载（~35 行）
- `SKILL_LOADER` ← `_SKILL_LOADER`（LocalSkillLoader，路径锚定 backend/skills 不变）
- `probe_skills()` ← stream() 里的探测段：`节点[Skill注册]` 日志

### 5. `app/agent_factory.py` — Agent 组装（~70 行）
- `build_agent()` ← `AgentService._build` 静态方法改为模块函数（参数签名不变；SKILL_LOADER 改从 agent_skills import）

抽到独立模块的符号去掉下划线前缀（不再是模块私有），符合项目惯例。

## agent.py 剩余结构（~180 行）
- `_PERMISSION_MODES`（单处使用，留编排侧）
- `AgentService`：`__init__`（credential）、`stream()`（开关判定→工作区/权限装配→`mcp_client`+`probe_mcp_tools`→`probe_skills`→`build_agent`→历史回放→主循环{事件翻译 + 权限 park/resume}→演示降级）、`_demo_answer`
- `agent_service` 单例（chat.py 引用不变）

主循环：REQUIRE_USER_CONFIRM 仍捕获 parked，其余事件交 `translator.feed()` 翻译后 yield；权限 park/resume 是编排本身，留在 stream() 内。`confirm.py`、`chat.py` 不动。

## 同步修改

- `tests/test_agent_tools.py`：`from app.agent import _tool_query` → `from app.agent_events import tool_query`，调用点改名
- `tests/test_skills.py`：`from app.agent import _SKILL_LOADER` → `from app.agent_skills import SKILL_LOADER`，调用点改名
- `backend/ARCHITECTURE.md` 轻同步：目录结构一节更新 agent.py 行并补 5 个新模块；4.3 节 `_tool_query()` 出处更新
